# restoranmenuvesiparis
Bu proje kapsamında PHP ve MySQL kullanılarak web tabanlı bir restoran otomasyon sistemi geliştirilmiştir.
Projenin amacı, restoran ortamında müşteri sipariş sürecini dijital hale getirerek hem müşteriler hem de işletme yönetimi için pratik bir çözüm sunmaktır.

Sistemde iki ana bölüm bulunmaktadır:

Müşteri tarafı

Admin (yönetici) tarafı

Müşteri tarafında kullanıcılar, restoran mantığına uygun olarak masa numarası ile giriş yapmaktadır. Giriş yapan müşteri, menüdeki ürünleri kategori bazlı olarak görüntüleyebilmekte, ürünleri sepete ekleyebilmekte ve sipariş oluşturabilmektedir.

Admin tarafında ise yetkili kullanıcılar, sisteme giriş yaparak verilen siparişleri görüntüleyebilmekte ve sipariş durumlarını yönetebilmektedir.

Ortaya çıkan ürün; çalışan, veritabanı ilişkileri doğru kurulmuş, gerçek hayata uygun bir restoran sipariş sistemidir.
